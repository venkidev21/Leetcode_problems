## 💡 Problem-Solving Approach

For each problem, I aim to follow a consistent workflow:

1. **Understand** — Identify inputs, outputs, and constraints.
2. **Analyze** — Consider edge cases and possible approaches.
3. **Optimize** — Compare approaches using time and space complexity.
4. **Implement** — Write a clear and maintainable Java solution.
5. **Validate** — Test normal cases, boundary cases, and edge cases.
6. **Review** — Revisit difficult problems and learn reusable patterns.
